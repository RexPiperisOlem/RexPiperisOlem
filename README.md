# Roger Crosby

## AI Workflow Governance and Documentation Systems

I build document-first systems for AI-assisted work where authority, evidence, review, provenance, and human approval need to remain visible.

My strongest work is not model training or autonomous-agent development. It is the operating layer around AI: workflow design, human gates, documentation architecture, quality control, behavioural continuity, claims discipline, and recovery of useful systems from messy source material.

## Current public proof of work

### [Human-Gated Agent System](https://github.com/RexPiperisOlem/human-gated-agent-system)

A twelve-role public reference architecture with structured handoffs, gate levels, tests, provenance controls, review logic, and explicit human authority.

### [Kaomoji Emotional Confusion Engine](https://github.com/RexPiperisOlem/kaomoji-engine)

A bounded, tested Python prototype built around visible symbolic mutation, deterministic test modes, and deliberately narrow technical claims.

### [PPLL Signal Archive](https://github.com/RexPiperisOlem/PPLL-Signal-Archive)

The public index for selected PPLL systems, art and licensing information, and approved releases.
